# Product Context

- **Project Goal:** To extend Roo Code with remote control capabilities, allowing users to interact with the extension from mobile devices.
- **Core Features:**
    - HTTP/REST API endpoints
    - WebSocket server for real-time streaming
    - Web UI accessible from any browser
    - Mobile device compatibility
    - Model switching capability
    - Mode switching capability
    - Tool approval workflow
    - Real-time message streaming
- **High-Level Architecture:**
    - RemoteServer component handling HTTP and WebSocket connections
    - Express-based REST API
    - WebSocket server for real-time communication
    - Integration with VSCode extension API
    - React-based frontend with state management
    - Message streaming system with partial updates
- **User Experience Goals:**
    - Seamless mobile interaction with desktop extension
    - Real-time feedback for all operations
    - Clear visual indication of system state changes
    - Simplified tool approval workflow
    - Consistent conversation display across devices
